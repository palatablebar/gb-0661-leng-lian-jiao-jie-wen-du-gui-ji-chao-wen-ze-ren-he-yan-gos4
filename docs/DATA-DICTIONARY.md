# 数据定义

shipment 是字符串货运批号，前导零保留。probe 是校准档案键。at 必须含时区偏移，进入规则后转换为 UTC。value 使用 Decimal，哨兵 N/A、NULL、未知、空串和短横线均为缺失，不能变成零。unit 为 C/℃ 或 F/℉；华氏先转摄氏，再加校准偏移。

每个 shipment+UTC时刻构成业务键。同键相同温度保留最早来源行，其余隔离；同键温度矛盾时全部隔离，避免任意选一条。探头修正范围为−80到80°C。交接区间采用[start,end)，端点属于后任。责任重叠或缺边保留证据，不任意分配。

采样间隔超过15分钟时整段未知，短间隔按线性轨迹处理。高于8°C的分钟与超出8°C的温差积分均为 Decimal；阈值交点精确切分。未覆盖的首尾时段未知。超温分钟与热暴露分别用min及°C·min，输出六位小数。

空文件、仅表头、全空行分别为EMPTY_FILE、HEADER_ONLY、BLANK_ROWS。运行无采样也会显示未知覆盖，不把未知认作达标。行数不包含表头和重复分段表头。原始行号按CSV逻辑记录结束时的物理行号保存。

## 分日关账

业务日以 UTC+08:00 的 [00:00, 次日00:00) 为准，关账截止为本地次日10:00。交接记录可选 `received_at`；带该字段且晚于记录开始所在业务日的次日10:00时，视为迟到交接，保留证据但不参与责任归属。跨零点批次在前后两个业务日各出一份账，切分点为本地零点。

每批账本字段：`span_minutes` 为本日窗口内交接与采样并集的分钟；`covered_minutes` 为可证实分钟（正常+超温）；`unknown_minutes` 为长缺测未知；`uncovered_minutes` 为责任未覆盖（`handover_gap` 责任未覆盖、`disputed` 责任争议、`late_handover` 交接迟到）。三者之和等于 `span_minutes`，未知与未覆盖不折算给任何责任方。`degree_minutes` 仅对可证实分钟积分。

关账策略 `verifiable` 发布可证实分钟并单列未知与未覆盖；`hold` 在仍有未知或未覆盖分钟时拒绝发布并保留旧版。幂等键为业务日+批次+策略+规则版本；同键重试不新增版本。账本版本只追加，切换有效版本是原子操作；恢复历史版本生成审计版本，分钟数与目标版本一致。确认记录按业务日与版本保存，只能确认当前有效版本。

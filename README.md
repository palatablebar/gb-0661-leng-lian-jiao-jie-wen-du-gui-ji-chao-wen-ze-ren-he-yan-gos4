# 冷链交接温度轨迹与超温责任核验

面向冷链质控员的轨迹复核工具。八个业务模块：轨迹采信、探头校准、交接区间、超温积分、质量隔离、责任对账、分日关账、批次复核。输入是带偏移时间的CSV采样、探头校准和交接区间；输出为责任方超温分钟、温差积分、逐行隔离证据，以及按业务日切分的责任账。

核心计算将温度折线按8°C交点及交接端点切分，长缺测不插值，重复键冲突全部隔离。详细定义见 `docs/DATA-DICTIONARY.md`，规则与测试登记见 `docs/DEPTH.md`。

## 分日关账口径

业务日按 UTC+08:00 的 [00:00, 次日00:00) 切分，关账截止为次日 10:00。跨零点批次在前后两个业务日分别计算，同一分钟只进一天。责任账把分钟分成三类，互不折算：

- **可证实分钟**：有交接归属且采样间隔不超过缺测阈值的分钟，含正常与超温分钟，以及热暴露 °C·min。
- **缺测未知**：长缺测造成的未知分钟，不插值，也不算任一方达标。
- **责任未覆盖**：交接缺口、责任重叠，以及在截止后才收到的交接记录所指时段；迟到记录保留证据但不参与归属。

同一业务日有两种发布策略：`verifiable`（可证实分钟发布）只发布可证实部分，未知与未覆盖单列；`hold`（留旧账等补齐）在仍有未知或未覆盖分钟时拒绝发布并保留旧版。同一关账重试（同批次、同策略、同规则版本）复用同一版本，不重复生成责任分钟；发布失败整体回滚，旧版继续有效；恢复历史版本生成新的审计版本且分钟数与目标版本一致。原始采样与已确认记录独立留存。

## 启动

```sh
docker compose up --build -d
```

访问 http://localhost:18200 ，初次启动自动导入配送脏样例。工具条可选择标准轨迹或旧设备编码后运行；轨迹采信页可粘贴自己的CSV与修改阈值。每个模块API可单独用内置样例试算，`GET /docs`查看请求结构。`POST /api/runs`持久化完整批次，输入摘要和参数一致时复用；隔离页可导出CSV。

```sh
docker compose config --quiet
docker compose exec -T app pytest -q
docker compose down
```

数据存于命名卷 records。停止和重新启动不丢失数据；需要清空全部本项目演示数据时，在确认无需保留后执行 `docker compose down -v`。

`app/modules/closing/` 为分日关账模块：`calendar.py` 定业务日与截止时刻，`ledger.py` 用 Decimal 切分责任分钟并给出未覆盖/未知原因，`service.py` 负责幂等发布、策略阻断、版本对比与恢复。关账相关列存于同库 `ledgers`、`ledger_confirmations`、`raw_samples` 三张表。

## 演示

1. 在超温积分页查看八批责任分段。
2. 进入交接区间核对09:30责任边界与未知段。
3. 进入质量隔离筛选CONFLICT并导出。
4. 选择标准轨迹运行，责任对账应四账相等。
5. 重跑同一样例不增加批次；批次复核使用当前版本确认，旧版请求返回409。
6. 进入分日关账页查看 2026-11-02 的预演与正式账；切换“留旧账等补齐”会因未知分钟被拒；重试发布不新增版本。

源码按 `app/modules/` 垂直切分。`sample_data/`含三份CSV及两份规则档案，`tests/`为模块与端到端测试。不接实时设备，不对未知温度补造数据。
